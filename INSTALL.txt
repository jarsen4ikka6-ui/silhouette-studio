КАК УСТАНОВИТЬ «СТУДИЮ РОЛИКОВ-СИЛУЭТОВ»

Плагин работает в приложении Claude для компьютера, во вкладке Code.
В обычном чате на claude.ai он работать не будет: плагину нужен доступ к компьютеру, чтобы ставить программы и рендерить видео.

УСТАНОВКА
1. Откройте приложение Claude, в боковом меню выберите Customize → Plugins.
2. Нажмите Add → Upload plugin и выберите этот .zip. Распаковывать архив не нужно.
3. Откройте вкладку Code и выберите любую папку.
4. Наберите в чате  /nomadapc  и выберите в списке  /nomadapc:video  (Enter).
   Плагин спросит язык и формат, предложит темы и напишет сценарий.
   Когда будет готова озвучка, снова вызовите /nomadapc:video — плагин сам предложит продолжить и соберёт ролик.
   Можно и без команды, просто написать: сделай ролик

ПРИ ПЕРВОМ ЗАПУСКЕ Claude сам:
- проверит Node.js и при необходимости поставит его. После этого Claude нужно один раз перезапустить;
- спросит, где создать папку студии (по умолчанию «Документы/Silhouette Studio»);
- скачает всё нужное и сделает пробный ролик. Это займёт 3–10 минут.

ЧТО НУЖНО КОМПЬЮТЕРУ
- Windows 10/11 или macOS.
- Около 8 ГБ свободного места.
- Видеокарта со свежим драйвером: нужна для расшифровки озвучки.
- Интернет.

ОБНОВЛЕНИЕ
Удалите старый плагин (Customize → Plugins → плагин → ⋯ → Remove) и загрузите новый архив.
Ролики, озвучки и сценарии лежат в папке студии и не пропадут.

ЕСЛИ НЕТ КНОПКИ Upload plugin
Распакуйте архив и скопируйте папку skills\video в C:\Users\<ваше имя>\.claude\skills\
(на Mac — в ~/.claude/skills/). Потом перезапустите Claude. Команда в этом случае будет /video.
