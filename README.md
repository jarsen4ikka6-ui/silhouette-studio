# Silhouette Studio — плагин nomadapc для Claude Code

Делает 2D-ролики с силуэтами для YouTube (1920×1080) в стиле Last Soul. Всё рисуется и звучит кодом: персонажи, локации, музыка, звуки.

- **Объяснялка** — с диктором. Озвучку вы делаете сами (например, на ElevenLabs), а плагин подгоняет под неё каждую сцену.
- **История** — без диктора: сцены, реплики, музыка.

Плагин ведёт вас от выбора темы до готового MP4:

1. **Формат и тема.** Формат выбираете кнопками, их 7: «Что если», «Как жили раньше», «Почему так» и другие. Темы предлагаются по три. Кнопка «Ещё темы ↻» даёт новые, без повторов.
2. **Сценарий.** Приходит файлами: полный текст и отдельный текст для озвучки.
3. **Озвучка.** Вы присылаете озвучку, плагин её расшифровывает и делает раскадровку под слова.
4. **Проверка.** Плагин сам проверяет кадры.
5. **Рендер.** Получаются две версии ролика: полная для YouTube и лёгкая (до 30 МБ) для телефона.

## Установка

Нужен Claude Code: приложение Claude для компьютера (вкладка Code) или терминал.

**Проще всего — архивом.**

1. Скачайте [nomadapc.zip](https://github.com/jarsen4ikka6-ui/silhouette-studio/releases/latest/download/nomadapc.zip).
2. В приложении Claude откройте **Customize → Plugins → Add → Upload plugin** и выберите скачанный архив. Распаковывать его не нужно.

**Через терминал Claude Code.** Так плагин потом будет обновляться сам:

```
/plugin marketplace add jarsen4ikka6-ui/silhouette-studio
/plugin install nomadapc@silhouette-studio
```

Потом в чате наберите **`/nomadapc`** и выберите **`/nomadapc:video`** (или просто напишите «сделай ролик»). Плагин предложит язык и формат, затем темы и сценарий, а по готовой озвучке соберёт ролик.

При первом запуске плагин сам:
- проверит Node.js и, если его нет, поставит. После этого один раз перезапустите Claude;
- спросит, где создать папку студии (по умолчанию «Документы/Silhouette Studio»);
- скачает зависимости и сделает пробный ролик на 3 секунды. Это занимает 3–10 минут.

## Что нужно компьютеру

- Windows 10/11, macOS или Linux.
- 8 ГБ свободного места. Из них ≈ 4 ГБ — модель расшифровки речи, она скачивается при первой озвучке.
- Видеокарта с поддержкой WebGPU (почти любая за последние 5–6 лет) и свежий драйвер. Нужна для расшифровки озвучки.
- Интернет: при установке и для шрифтов при рендере.

## Обновление

- **Ставили архивом:** удалите плагин (**Customize → Plugins** → nomadapc → ⋯ → **Remove**), скачайте [nomadapc.zip](https://github.com/jarsen4ikka6-ui/silhouette-studio/releases/latest/download/nomadapc.zip) заново и загрузите его.
- **Ставили через терминал:** выполните `/plugin marketplace update silhouette-studio`.

После обновления плагин сам обновит движок студии при следующем запуске. Ваши ролики, озвучки, сценарии и свои локации (`src/custom`) не пострадают.

## Где что лежит в студии

| Папка | Что там |
|---|---|
| `script/` | сценарии (`.md`) и тексты для озвучки (`-ozvuchka.txt`) |
| `voice/` | сюда класть озвучку |
| `out/` | готовые ролики и превью кадров |
| `boards/` | раскадровки |
| `src/custom/` | свои локации и предметы |
| `topics-history.md` | журнал тем, чтобы они не повторялись |

## Для разработчика

| Путь | Что там |
|---|---|
| `template/` | рабочий движок; правки делаются здесь |
| `pack.mjs` | собирает плагин из движка в `silhouette-studio/plugins/nomadapc` и архив `dist/nomadapc.zip` |
| `.githooks/` | перед коммитом запускается `pack.mjs`, после коммита всё отправляется на GitHub, а архив обновляется в релизе |

После клонирования включите хуки: `git config core.hooksPath .githooks`.
