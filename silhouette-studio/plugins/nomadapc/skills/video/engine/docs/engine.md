# Движок: как устроена раскадровка

Ролик = доска `boards/<ролик>.json`. Команда `npm run timing -- <ролик>` переводит её в `data/<ролик>.json` с секундами и генерирует музыку. Рендер и превью работают уже с `data/`.

Холст 1920×1080, 30 кадров/с. Координаты сцены: x слева направо (0–1920), y сверху вниз (0–1080). Пол в большинстве локаций на **y ≈ 900**: там стоят ступни персонажей.

## 1. Верх доски

```json
{
  "id": "phones",                 // короткий id латиницей (имена музыки: music/<id>-N.wav)
  "mode": "explainer",            // explainer (с диктором) | story (без диктора)
  "language": "ru",
  "voiceAt": 0.5,                 // с какой секунды ролика стартует озвучка
  "tail": 3.5,                    // сколько секунд ролик идёт после последнего слова
  "musicDb": -12,                 // громкость музыки (под диктором движок сам убавляет ещё на 8 дБ)
  "sfxDb": -10,                   // громкость звуков
  "music": [ { "mood": "bright", "from": 0 }, { "mood": "sad", "from": "@но не все так романтично" } ],
  "musicFile": "music/my.mp3",    // необязательно: свой трек из public/ вместо генерации
  "looks": { "hero": { "top": "hoodie", "color": "#d0703a" } },
  "scenes": [ ... ]
}
```

- `voice` указывать не нужно: его берёт из расшифровки `npm run timing`.
- Настроения музыки (`mood`):
  - `bright` — лёгкая, «любопытная», для объяснялок;
  - `sad` — грустное фортепиано;
  - `hope` — надежда, светлее.

  Музыка меняется по главам, между частями идёт плавный переход 2 с.

## 2. Время: фразы вместо секунд

С озвучкой время пишется **словами диктора**. Фразу берите из `transcripts/<ролик>.txt` (3–5 слов подряд). Сравнение идёт без учёта регистра, знаков препинания и разницы ё/е.

| Где | Как | Что значит |
|---|---|---|
| `"start": "Рука нащупывает"` | у сцены | сцена начинается за 0.25 с до этих слов (`"shift": 0.3` сдвигает) |
| `"at": "@Телефона нет"` | любое поле | секунда этих слов от начала сцены |
| `"at": "@Телефона нет\|+0.4"` | | то же со сдвигом |
| `"dur": "@все до одного\|end"` | у текста, оверлея, предмета | длится от своего `at` до конца этих слов |
| `"from": "@фраза"` | в `music` | смена музыки за 1 с до фразы |

Фраза ищется **после начала сцены**. Если такие слова звучат несколько раз, возьмите более длинный кусок.

Без озвучки (режим История): у сцены пишется `"dur": 4.5`, тогда следующая сцена начинается через 4.5 с. Все `at` задаются секундами от начала сцены.

Числа Whisper записывает цифрами: «2014», «23», «89». В фразах пишите так же, как в `transcripts/<ролик>.txt`.

## 3. Сцена

```json
{
  "note": "просыпается, тянется к тумбочке",     // для себя, видно в таблице сцен
  "start": "Ты просыпаешься",
  "location": "bedroom", "params": { "tod": "dawn", "lamp": false },
  "camera": { "zoom": [1, 1.15], "focus": [[960, 600], [820, 620]] },
  "actors": [ ... ], "props": [ ... ], "texts": [ ... ], "overlays": [ ... ],
  "sfx": [ { "name": "buzz", "at": "@телефон" } ],
  "ambience": "room",
  "rain": false, "vignette": 0.6, "fadeIn": 0.5, "fadeOut": 0.5
}
```

Вместо локации может стоять карточка: `"card": { "kind": "hook", "text": "…" }` (чёрный фон, текст по центру).
- `quote` — `text`, `author`: цитата;
- `hook` — `text`: вопрос-крючок;
- `end` — `title`, `text`: финальная карточка.

**Камера (главное в новом стиле).** Камера задаётся *планом*, а не зумом: движок сам кадрирует героя.

```json
"camera": { "shot": "medium", "on": "hero", "move": "push", "amount": 0.06,
            "cuts": [ { "at": 1.8, "shot": "face", "on": "ann" }, { "at": "@и тут", "shot": "insert", "on": [800, 330], "size": 900 } ] }
```

| `shot` | что в кадре | когда |
|---|---|---|
| `wide` | вся локация (с `size` — кусок шириной `size` px вокруг `on`) | открыть место, показать толпу |
| `full` | герой в полный рост, с запасом сверху | действие, походка |
| `medium` | по пояс | разговор, реакция |
| `close` | плечи и голова | эмоция |
| `face` | только лицо | шок, решение, шутка |
| `insert` | деталь: `on: [x, y]`, `size` — ширина куска | доска, телефон, бумага, портрет |
| `pov` | глазами героя: `on: [x, y]`, `size`, камера в руке сама | «что он видит» |
| `ots` | через плечо: `on` — собеседник, `over` — чьё плечо, `overSide` | диалог двоих |

- `on` — id персонажа или точка `[x, y]`. Без `on` план берёт первого персонажа.
- `move` — движение за время плана: `push` (наезд, по умолчанию), `pull` (отъезд), `left`, `right`, `up`, `down`, `drift` (плывёт), `static`. Сила — `amount` (0.04–0.12).
- `handheld`: 0.2–0.6 — лёгкая «камера в руке».
- `dof` — размытие фона в px (у `medium`/`close`/`face`/`ots` уже есть по умолчанию; `0` — выключить). У `insert` и `pov` то, на что смотрит камера (центр кадра), всегда резкое — размываются только края. Сильный `dof` деталям не ставьте.
- `cuts` — склейки внутри сцены: с `at` действует новый план. Так одна сцена даёт 2–3 разных ракурса.
- Камера никогда не стоит мёртво: даже `wide` по умолчанию медленно наезжает.
- **Правило ритма:** каждые 2–4 секунды новый план. Не ставьте два одинаковых плана подряд. Хорошая цепочка: `wide` → `medium` → `face` → `insert` → `ots` → `wide pull`.
- Старый способ (`zoom` числом или `[от, до]`, `focus` точкой) продолжает работать.

**Передний план** (`fg`) — размытый предмет перед камерой, даёт глубину:
`"fg": [ { "kind": "plant", "x": 300 } ]`. Виды: `post` (столб), `plant`, `leaves` (листья сверху), `railing` (перила), `lamp` (абажур сверху), `curtain`, `glass` (блики стекла). Поля: `x` (в координатах сцены, с параллаксом), `blur`, `color`, `flip`.

**Плёнка** (`look`) включена всегда: тёплый засвет из угла, пылинки, зерно. Настройка: `"look": { "grain": 0.07, "dust": 1, "leak": "#ffb46e", "leakSide": "right", "tint": "#ffd9b0" }`; `"look": false` — выключить (например, для карточек-схем).

**Звуки** (`sfx[].name`): `alarm` будильник, `birds` птицы, `buzz` вибрация, `click`, `dial` гудок, `ding` уведомление, `rain`, `rise` нарастание, `room` гул комнаты, `sigh` вздох, `step` шаг, `tick` тиканье, `whoosh`, `zap` разряд. Шаги для идущих и бегущих персонажей добавляются сами.

**Фоновый звук на всю сцену** (`ambience`): `rain`, `rain-indoor`, `birds`, `room`. Шума толпы нет и не будет: людные места (рынок, улица, кафе) озвучиваются только музыкой и точечными звуками. Если сомневаешься — без фона лучше, чем с шумом.

## 4. Персонажи (`actors`)

```json
{ "id": "hero", "look": "hero", "x": [700, 1100], "y": 900, "scale": 1.2,
  "legs": "walk", "arms": "phone", "mood": "tired", "facing": "right",
  "lookX": 0.3, "lookY": -0.5, "phoneLight": true, "rim": "#9fc4ff", "glow": "#ff4a2a",
  "keys": [ { "at": "@и тут", "arms": "shrug", "mood": "surprised", "facing": "front" } ] }
```

- **Положение.**
  - `x` / `y` — точка между ступнями. `[от, до]` двигает персонажа за сцену. Для `walk`/`run` задавайте `x` диапазоном.
  - `scale` — 1 соответствует росту ≈ 390 px. Крупный план: 1.3–1.6 плюс зум камеры.
- **Внешность** — `look`: имя из `looks` вверху доски или объект:
  - `skin` — цвет кожи: `light` | `fair` | `tan` | `olive` | `brown` | `dark` или `"#rrggbb"`. Без `skin` цвет выбирается сам по внешности (у одной внешности всегда один и тот же). Подбирайте по месту и эпохе: ацтеки — `tan`/`brown`, Африка — `brown`/`dark`, Скандинавия — `light`/`fair`;
  - `top`: `jacket` (по умолчанию) | `coat` (пальто, халат учёного) | `dress` | `robe` (накидка, мантия) | `hoodie` | `tee` | `raincoat` | `none` (голый торс); `color` — цвет одежды; `trim` — цвет пояса и каймы у `robe`; `pants` — цвет штанов (`"skin"` — голые ноги); `shoes` — цвет обуви;
  - `hair`: `short` (по умолчанию) | `ponytail` | `bun` | `long` | `curls` (седые кудри) | `headband` (волосы + повязка) | `scarf` (платок закрывает голову) | `none` (лысый); `hairColor` — цвет волос; у `headband` и `scarf` цвет ткани — `hatColor`;
  - `glasses`: true;
  - `hat`: `cap` | `beanie` | `crown`, `hatColor`;
  - `skirt`: true.

  Свой стиль: люди с настоящим цветом кожи (лицо, руки, ноги, уши), волосы, белые глаза-блюдца с зрачками, брови и рот. У каждого героя свой яркий цвет одежды (бирюзовый, горчичный, фиолетовый, красный, белый халат).

  Руки, которые висят вдоль тела, сами отходят в стороны от длинной одежды (`robe`, `dress`, `coat`) — не рисуйте их поверх одежды. В профиль видна только ближняя рука.

  Главный герой ролика — `looks.hero` (или первая внешность в `looks`). Его кожу получают и руки «от первого лица»: в своих предметах берите цвет через `useHeroSkin()` из `src/Character`, а не рисуйте чёрным. Чёрный `BODY` — только для теней и далёких силуэтов.

  Главный герой во всём ролике выглядит одинаково (`looks`). Прохожие разные, у каждого 1–2 цветные детали.
- **Поза.**
  - `legs`: `stand` | `walk` | `sit` | `run`.
  - `arms`: `rest` | `phone` | `mug` | `reach` | `cheer` | `walk` | `hips` | `think` | `pocket` | `ear` (у уха — «звонит») | `write` | `point` | `shrug` | `chalk` (пишет мелом на доске) | `wave` (машет) | `hold` (держит перед собой) | `fold` (руки скрещены).
- **Эмоция** (`mood`): `neutral` | `tired` | `sad` | `worried` | `happy` | `angry` | `surprised` | `smug` (хитрый) | `sleep`. Голова слегка наклоняется под эмоцию.
  - Взгляд: `lookX` / `lookY` от −1 до 1.
  - Поворот: `facing` — `front` | `left` | `right`. Правила поворота — раздел 11.8: человек смотрит на того, с кем говорит, или на предмет, с которым что-то делает; идёт — смотрит туда, куда идёт.
  - Жесты `reach` и `point` делаются вперёд, по направлению взгляда, ближней к зрителю рукой. Поэтому тянуться к предмету можно только в профиль (`facing` в сторону предмета). В той же руке `mug` и `phone`.
- **Свет.**
  - `phoneLight` — голубое свечение экрана на лице.
  - `rim` — контурная подсветка цветом (`rimSide`: `left` | `right`).
  - `glow` — свечение вокруг (злость).
- **Смена позы по ходу сцены** — `keys`. Каждый ключ с `at` меняет `arms`, `legs`, `mood`, `lookX`, `lookY`, `facing`.
- **Сидячий персонаж.**
  - При `legs: "sit"` таз опускается: сиденье должно быть на высоте ≈ `y − 63·scale` (в toon — `y − 75·scale`, плечи на `y − 181·scale`).
  - Под сидящим всегда сиденье. В toon: `t-stool`, `t-chair` или `t-sofa` с тем же `x` и `y`, без `front`.
  - Кладите персонажа на стул так: `chair.y = actor.y`, а `x` стула примерно равен `x` персонажа.
  - На кровати спальни: `y ≈ 980` при `scale` 1.2.
  - В метро сиденье на высоте ≈ 680, значит `y ≈ 772` при `scale` 1.3.
- **Руки.**
  - В позе `write` руки на высоте ≈ `y − 123·scale` (туда ставится `notebook`).
  - В позе `ear` рука у головы.

## 5. Реплики (`texts`)

```json
{ "kind": "say", "text": "Ну и где он?", "actor": "hero", "at": "@где", "dur": 2.5 }
```

- `say` — реплика над головой.
- `think` — мысль (курсив, тёплый цвет).
- `offscreen` — голос за кадром сбоку (`side`: `left` | `right`).
- `notif` — уведомление-плашка у персонажа.
- Без `actor` нужно задать `x` / `y` на экране.

**Реплики короткие:** 2–6 слов. Диктор и реплики не повторяют друг друга.

## 6. Оверлеи (`overlays`): инфографика поверх кадра

| kind | поля | для чего |
|---|---|---|
| `caption` | `text` | подпись-источник внизу слева («Maguire и др., PNAS, 2000», «Первая неделя») |
| `counter` | `from`, `to`, `label`, `suffix`, `time`, `format: "int" \| "mmss"`, `x`, `y` | число бежит от и до |
| `bars` | `items: [{label, value, color}]`, `x`, `y` | 2–3 полоски-сравнения (value в %) |
| `meter` | `label`, `from`, `to`, `color`, `x`, `y` | вертикальная шкала |
| `term` | `title`, `text` | термин с определением |
| `tip` | `title`, `text` | совет |
| `clock` | `time`, `ampm` | часы |

**Оверлеи нового стиля** (шрифт Inter, мел — Caveat):

| kind | поля | для чего |
|---|---|---|
| `pill` | `text`, `y` | тёмная плашка-подпись внизу по центру («≈ 10 детей на женщину») |
| `source` | `text` | мелкий источник внизу слева |
| `calendar` | `text` или `[{at, text}]` | отрывной календарь в углу, листается («YEAR 1» → «YEAR 20») |
| `stat` | `label`, `from`, `to`, `time`, `prefix`, `suffix`, `x`, `y` | карточка с бегущим числом |

**Число всегда докручивается до конца.** У `stat`, `counter`, `meter`, `bars` число бежит `time` секунд, потом ≥ 1.2 с висит готовое. Если `dur` короче, `npm run timing` сам продлит показ до конца сцены. Если и сцены не хватает, печатается «ВНИМАНИЕ» — тогда начните число раньше (`at`) или не ставьте `dur`. Любой текст на экране виден не меньше 1.2 с.
| `blocks` | `word`, `top`, `bottom`, `aside` | заголовок из падающих цветных кубиков-букв (название главы) |
| `label` | `text`, `x`, `y`, `tx`, `ty`, `color` | подпись со стрелкой-линией к точке `tx`,`ty` |
| `panel` | `title`, `mark: "check" \| "cross"`, `text`, `x`, `y`, `w`, `h`, `color` | стеклянная карточка «за / против» |
| `question` | `text` | крупный вопрос курсивом на тёмной плашке |
| `heading` | `text`, `sub`, `y` | простой заголовок |
| `chalk` | `text`, `x`, `y`, `size`, `color`, `speed` | надпись мелом, пишется по буквам (координаты **сцены** — на доске локации `classroom`) |
| `chalkfigs` | `count`, `x`, `y`, `size`, `gap`, `every`, `color`, `cross: [номера]` | человечки мелом рисуются по одному, некоторые зачёркиваются красным |

У всех есть `at` и `dur`. **Оверлей не должен закрывать лицо героя**: ставьте его в свободную часть кадра (`x` / `y`) или двигайте героя.

## 7. Локации (`location` + `params`)

**Новый стиль (берите их в первую очередь).** Детальные, тёплый вечерний свет, ореолы ламп.
- `cafe-street` — вечерняя улица: кафе с маркизой и гирляндой, голуби, фонарь, почтовый ящик, просвет заката. `sign` — надпись вывески, `door` — номер дома, `lamp: false`.
- `classroom` — большая меловая доска (пишем на ней `chalk` / `chalkfigs`, доска x 300–1620, y 100–600), окно с закатом, лампы, полки. `poster` — год на постере.
- `living` — гостиная/столовая: розовые обои в горошек, рамки, окно в сумерках. `wall` — цвет стен. С `longtable` — семейный ужин.
- `lab-dark` — тёмно-синяя «научная» сцена с сеткой и светящейся платформой. `accent` — цвет свечения. Сюда `holo`, `genes`.
- `gallery` — дворцовая галерея: два портрета королей, красные шторы, свеча. `names: "PHILIP III|CHARLES II"`, `subs` — подписи, `bars: "0.5|0.8"` — полоски под портретами.
- `porch` — крыльцо дома на закате, перила, птицы. Сюда `rockchair`.
- `village` — деревня: домики, деревья, забор, грядки, флажки. `tod: "evening"`.
- `savanna` — саванна на закате с акациями и большим солнцем.
- `island` — остров в море, волны, песчаный берег. `ships` — сколько парусников.
- `forest` — лес с лучами света.
- `studio` — мягкий бежевый фон с кругом света: для объяснений, кубиков-заголовков. `color`.

**Старые (стиль Last Soul — тёмные, силуэтные; использовать только если подходит по смыслу).**

**Базовые.**
- `bedroom` — спальня.
  - `tod`: `night` | `dawn` | `morning`;
  - `lamp`: true; `lampOffAt`: секунды;
  - `rain`: true/false (по умолчанию дождь идёт только ночью).
- `kitchen` — кухня.
  - `crosses`: сколько дней зачёркнуто в календаре;
  - `hour`: время на часах, например 7.8.
- `street` — ночная улица под дождём с фонарями.
- `meadow` — светлый луг для финала.

**Из ролика про телефоны.**
- `city` — панорама города.
  - `tod: "dawn"`;
  - `screensOffAt` — волной гаснут голубые экраны в окнах;
  - `blackoutAt` — гаснет весь свет.
- `globe` — Земля из космоса; `lightsOffAt` — гаснут огоньки.
- `cafe` — кофейня с меню и стойкой.
- `crossroad` — перекрёсток с зеброй и светофором; `tod: "evening"`.
- `entrance` — подъезд: почтовые ящики и записка.
- `london` — улица с домами и Биг-Беном.
- `brain` — схема головы с гиппокампом.
  - `growAt` — гиппокамп растёт;
  - `shrink`: true — уменьшается.
- `lab` — белая комната эксперимента.
  - `timerAt`, `timerFrom` (секунды), `timerSpeed` — таймер на стене.
- `grid` — сетка маленьких комнат с людьми (`cols`, `rows`): «тысячи людей».
- `metro` — вагон: окна, реклама, синие сиденья.
- `yard` — вечерний двор у панельки.

## 8. Предметы (`props`)

```json
{ "kind": "notebook", "x": 960, "y": 780, "scale": 0.8, "at": "@записала", "dur": 3, "front": true, "flip": false, "params": { "writeAt": 1 } }
```

- `x` / `y` — точка, где предмет стоит на полу (у висящих в воздухе — центр). Можно задать `[от, до]`.
- `front`: true — предмет рисуется поверх персонажей (стол перед сидящим, тетрадь в руках).
- `on`: `"t-table"` — поставить вещь на поверхность другого предмета сцены (toon). `x` и `y` движок возьмёт сам (`dx` — сдвиг от центра). Список поверхностей и их высоты — раздел 11.8.

## 9. Новая локация или предмет

1. Откройте `src/custom/locations.tsx` (или `props.tsx`) и посмотрите пример. Для образца годятся и готовые локации в `src/locations.tsx` и `src/locations2.tsx`: окна домов (`Windows`), дождь в окне, градиенты.
2. Локация — компонент `({ t, params }) => <svg viewBox="0 0 1920 1080">…</svg>`. Предмет — `<g>` вокруг точки (0, 0).
3. Стиль (как в `src/locations3.tsx` — берите оттуда `Glow`, градиенты, окна, кирпич, растения):
   - плоский вектор, мягкие градиенты, без обводок, много деталей (вывески, растения, рамки, лампы);
   - тёплый вечерний свет: у каждой лампы и окна мягкий ореол (`Glow`), лучи (`Shaft`);
   - палитра насыщенная, но мягкая (лаванда, терракота, бирюза, персик); персонажи (кожа и одежда) должны читаться на фоне;
   - пол на y ≈ 900.
4. Анимация — только от `t` (секунды сцены). Случайность берите из `rand(i)` (`src/util.ts`): она одинакова в каждом кадре. `Math.random` нельзя.
5. Внутри SVG id градиентов делайте уникальными через `useId()`, как в примере.
6. Зарегистрируйте компонент в `CUSTOM_LOCATIONS` / `CUSTOM_PROPS` и проверьте типы: `npx tsc --noEmit -p .`.
7. Одно место внутри ролика выглядит одинаково, но в каждом новом ролике у него другие время суток, палитра и предметы.

## 11. Стиль toon (мультик «Что, если бы ты…»)

Включается в верхе доски: `"style": "toon"`. Люди рисуются как в мультсериале: белые круглые головы, тёмная обводка, яркая одежда, рот двигается под громкость озвучки. Всё остальное (сцены, фразы, камера, `at`) — как обычно.

### 11.1 Верх доски

```json
{
  "style": "toon",
  "mode": "explainer",
  "cast": { "ГЕРОЙ": "hero", "МАМА": "mom", "КАССИРША": "cashier" },
  "looks": { "hero": "char:artem", "mom": { "top": "shirt", "color": "#c96f5a", "hair": "ponytail", "hairColor": "#6b3f2a" } },
  "hud": [
    { "at": "@В первый день", "text": "ДЕНЬ 1", "place": "left" },
    { "at": "@потратил всего", "text": "ПОТРАЧЕНО: 3 400" }
  ],
  "bubbles": true,
  "scenes": [ ... ]
}
```

- `cast` — какое имя из сценария (`МАМА:` в `script/<ролик>.md`) какой персонаж в кадре (`id` в `actors`).
- `looks` — как в разделе 1; `"char:<имя>"` — свой персонаж из `characters/<имя>.json` (поле `look`).
- `hud` — плашки сверху, держатся через все сцены до следующей на том же месте. `place`: `right` (золотая, по умолчанию), `right2` (золотая под ней), `left` (тёмная). Если текст тот же, а число в конце другое, число накручивается: «ПОТРАЧЕНО: 3 400» → «ПОТРАЧЕНО: 184 000». Пустой `text` убирает плашку.
- `bubbles`: `true` (по умолчанию) — пузыри реплик ставятся сами; `false` — рот двигается, пузырей нет; `"manual"` — ничего не ставится, реплики пишешь сам в `texts`.

### 11.2 Реплики и рот

1. Озвучка одним голосом. В сценарии реплики подписаны: `МАМА: Убери, я сказала.`
2. `npm run transcribe -- <ролик> --lang ru`, потом `npm run lines -- <ролик>` → видно, кто когда говорит.
3. `npm run timing` сам кладёт в каждую сцену пузыри (`say`) над говорящим и открывает ему рот, пока звучат его слова. Длинная реплика режется на пузыри по предложениям.
   - Говорящего нет в кадре, но люди есть — пузырь у края кадра (`offscreen`), timing предупредит. Сцена без людей — голос просто звучит.
   - Свой `say` руками в этой сцене на то же время — автоматический не ставится.
4. Пузырь сам выбирает место: над головой; при крупном плане — сбоку, где нет соседа; если сбоку тесно — над головой у верха кадра.

### 11.3 Персонажи

Поля `Look` (раздел 3) плюс только для toon:
- `under` — кофта с капюшоном под курткой;
- `apron` — фартук (продавщица, повар);
- `beard`: `mustache` | `beard`;
- `hair: "spiky"` — торчащие волосы; `hair: "scarf"` — платок с цветочками (`hatColor` — ткань, `hairColor` — чёлка);
- `hat: "beanie"` — вязаная шапка;
- `extra` — своя деталь из `src/custom/characters.tsx` (для своего персонажа: особая причёска, значок).

Позы, руки, ноги, настроение и `keys` — как в разделе 4. Сидит (`legs: "sit"`) — бёдра на 75 выше пола, ставь `t-chair` или `t-sofa` в тот же `x`.

### 11.6 Оверлеи toon

- `{ "kind": "plate", "text": "Ни банка, ни договора", "at": "@ни банка" }` — жёлтая плашка внизу, чуть наклонена. Для правил силы и коротких фактов.
- `{ "kind": "shout", "text": "тебя ищет *весь мир*", "at": "@искать весь мир" }` — крупные слова по центру, `*звёздочками*` — золотые. Для забегания вперёд и громких поворотов. Лучше на `t-plain` или `t-city`.
- `{ "kind": "day", "text": "ДЕНЬ 1", "sub": "потрачено: 0", "at": "@В первый день", "dur": 2.2 }` — жёлтая косая лента на весь экран, въезжает и уезжает. На каждый новый день, неделю, месяц.
- `{ "kind": "bignum", "text": "184 650 ₽", "label": "в одном чеке", "at": "@сто восемьдесят" }` — огромное золотое число по центру, накручивается от нуля (`from` — от другого). На каждую громкую цифру диктора. Лучше на `t-plain`.
- `{ "kind": "title", "text": "Что, если бы у тебя были *бесконечные деньги*", "sub": "Серия 1", "at": 0.2 }` — название серии с лучами. Один раз, сразу после хука.

### 11.7 Темп и наполнение

Ролик конкурентов держит зрителя тем, что картинка меняется постоянно и показывает каждое слово.

- **Новый кадр каждые 3–4 секунды.** Минута озвучки — 15–20 сцен. Сцена дольше 5 секунд — только если в ней идёт диалог.
- **Всё, о чём говорит диктор, видно в кадре:** «карта» — `t-card` крупно, «пришла в конверте» — `t-entrance` + `t-envelope`, «такси» — `t-taxi`, «шаурма» — `t-shawarma`, «весь мир» — `t-city` + `shout` или `t-globe`, «хлеб подорожал» — `t-bread` с `price` и `old`, «чат класса» — `t-phone`.
- **Крупные планы предметов:** камера `insert` с `on: [x, y]` и `size`, или предмет крупно на `t-plain` (`scale` 2–3).
- **В людных местах — люди:** класс — `t-crowd` `class`, магазин — `queue`, улица — `street`, «тебя узнают» — `fans`.
- **Каждая цифра** — `bignum` или `hud`; **каждый новый день** — `day`; **правило силы** — `plate`.
- Не два одинаковых кадра подряд: меняй план (общий → средний → крупный → предмет) и место.

### 11.8 Направление, высоты и постановка

Правила сняты с ролика конкурента. Нарушение любого из них зритель замечает сразу.

**Куда смотрят люди**
- Двое разговаривают — стоят в профиль **лицом друг к другу**. В toon движок сам поворачивает к ближайшему человеку того, у кого нет `facing`.
- Человек что-то делает с предметом (берёт письмо, платит на кассе, жмёт кнопку) — стоит **лицом к предмету**, предмет перед ним, а не за спиной.
- `reach` и `point` идут вперёд, туда, куда он смотрит. Лицом к нам (`front`) тянуться к предмету нельзя: рука уйдёт в сторону экрана.
- Идёт или бежит (`x: [от, до]`) — смотрит по ходу. Движок поворачивает сам.
- Лицом к нам (`front`) — когда человек говорит со зрителем, реагирует (шок, радость) или сидит за столом/партой, который стоит перед ним.

**Машины**
- `t-taxi` и `car` нарисованы капотом и фарой вправо. Едут влево (`x` убывает или `drive` < 0) — движок разворачивает их сам. Сзади — короткий багажник и красный фонарь.

**Высоты (при `scale` 1; `y` предмета — пол)**

| Поверхность | Верх над полом | Кто рядом |
|---|---|---|
| `t-table`, `t-desk` | 130 | сидящему по грудь, стоящему по пояс |
| `t-counter` | 170 | кассир за ней виден по пояс |
| `t-stool`, `t-chair` | 88 | сиденье |
| `t-sofa` | 96 | сиденье |

Вещь на стол, кассу, табурет ставь через `"on"`, а не считай `y` руками:
`{ "kind": "t-money", "on": "t-table", "dx": 60, "params": { "n": 3 } }`.

**Кухня и стол (как у конкурента)**
- Двое за столом говорят: оба сидят боком на `t-stool`/`t-chair` **лицом друг к другу**, стол между ними и **позади** них (без `front`). Вещи на столе — через `on`.
- Один человек за столом лицом к нам: стул без `front`, стол перед ним с `front: true`, тот же `x`.
- Нельзя: сидящий боком **внутри** стола с `front` — получится, что стол проходит сквозь него.

**Что движок делает сам и о чём предупреждает**
`npm run timing` печатает:
- `ПОПРАВИЛ САМ:` — развернул машину, поставил вещь ровно на стол, повернул идущего по ходу. Проверь, что так и задумано.
- `ВНИМАНИЕ:` — тянется к тому, что за спиной; тянется лицом к нам; стоит спиной ко всем; сидит без стула; сидит боком внутри стола; вещь висит в воздухе; двое стоят друг в друге. **Каждое `ВНИМАНИЕ` исправь до рендера** или убедись, что так и надо (например, человек уходит от всех).
