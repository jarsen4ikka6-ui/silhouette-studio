# Движок: как устроена раскадровка

Ролик = доска `boards/<ролик>.json`. Команда `npm run timing -- <ролик>` переводит её в `data/<ролик>.json` с секундами и генерирует музыку. Рендер и превью работают уже с `data/`.

Холст 1920×1080, 30 кадров/с. Координаты сцены: x слева направо (0–1920), y сверху вниз (0–1080). Пол в большинстве локаций на **y ≈ 900**: там стоят ступни персонажей.

## 1. Верх доски

```json
{
  "id": "phones",                 // короткий id латиницей (имена музыки: music/<id>-N.wav)
  "mode": "explainer",            // explainer (с диктором) | story (без диктора)
  "language": "ru",
  "voiceAt": 0.5,                 // с какой секунды ролика стартует озвучка
  "tail": 3.5,                    // сколько секунд ролик идёт после последнего слова
  "musicDb": -12,                 // громкость музыки (под диктором движок сам убавляет ещё на 8 дБ)
  "sfxDb": -10,                   // громкость звуков
  "music": [ { "mood": "bright", "from": 0 }, { "mood": "sad", "from": "@но не все так романтично" } ],
  "musicFile": "music/my.mp3",    // необязательно: свой трек из public/ вместо генерации
  "looks": { "hero": { "top": "hoodie", "color": "#d0703a" } },
  "scenes": [ ... ]
}
```

- `voice` указывать не нужно: его берёт из расшифровки `npm run timing`.
- Настроения музыки (`mood`):
  - `bright` — лёгкая, «любопытная», для объяснялок;
  - `sad` — грустное фортепиано;
  - `hope` — надежда, светлее.

  Музыка меняется по главам, между частями идёт плавный переход 2 с.

## 2. Время: фразы вместо секунд

С озвучкой время пишется **словами диктора**. Фразу берите из `transcripts/<ролик>.txt` (3–5 слов подряд). Сравнение идёт без учёта регистра, знаков препинания и разницы ё/е.

| Где | Как | Что значит |
|---|---|---|
| `"start": "Рука нащупывает"` | у сцены | сцена начинается за 0.25 с до этих слов (`"shift": 0.3` сдвигает) |
| `"at": "@Телефона нет"` | любое поле | секунда этих слов от начала сцены |
| `"at": "@Телефона нет\|+0.4"` | | то же со сдвигом |
| `"dur": "@все до одного\|end"` | у текста, оверлея, предмета | длится от своего `at` до конца этих слов |
| `"from": "@фраза"` | в `music` | смена музыки за 1 с до фразы |

Фраза ищется **после начала сцены**. Если такие слова звучат несколько раз, возьмите более длинный кусок.

Без озвучки (режим История): у сцены пишется `"dur": 4.5`, тогда следующая сцена начинается через 4.5 с. Все `at` задаются секундами от начала сцены.

Числа Whisper записывает цифрами: «2014», «23», «89». В фразах пишите так же, как в `transcripts/<ролик>.txt`.

## 3. Сцена

```json
{
  "note": "просыпается, тянется к тумбочке",     // для себя, видно в таблице сцен
  "start": "Ты просыпаешься",
  "location": "bedroom", "params": { "tod": "dawn", "lamp": false },
  "camera": { "zoom": [1, 1.15], "focus": [[960, 600], [820, 620]] },
  "actors": [ ... ], "props": [ ... ], "texts": [ ... ], "overlays": [ ... ],
  "sfx": [ { "name": "buzz", "at": "@телефон" } ],
  "ambience": "room",
  "rain": false, "vignette": 0.6, "fadeIn": 0.5, "fadeOut": 0.5
}
```

Вместо локации может стоять карточка: `"card": { "kind": "hook", "text": "…" }` (чёрный фон, текст по центру).
- `quote` — `text`, `author`: цитата;
- `hook` — `text`: вопрос-крючок;
- `end` — `title`, `text`: финальная карточка.

**Камера.**
- `zoom` — число или `[от, до]` за сцену.
- `focus` — точка `[x, y]` или `[[x1, y1], [x2, y2]]`, если камера плывёт.
- Камера сама не выезжает за край картинки.
- Медленный наезд `[1, 1.08]` оживляет почти любую сцену.

**Звуки** (`sfx[].name`): `alarm` будильник, `birds` птицы, `buzz` вибрация, `click`, `crowd` толпа, `dial` гудок, `ding` уведомление, `rain`, `rise` нарастание, `room` гул комнаты, `sigh` вздох, `step` шаг, `tick` тиканье, `whoosh`, `zap` разряд. Шаги для идущих и бегущих персонажей добавляются сами.

**Фоновый звук на всю сцену** (`ambience`): `rain`, `rain-indoor`, `birds`, `room`, `crowd`.

## 4. Персонажи (`actors`)

```json
{ "id": "hero", "look": "hero", "x": [700, 1100], "y": 900, "scale": 1.2,
  "legs": "walk", "arms": "phone", "mood": "tired", "facing": "right",
  "lookX": 0.3, "lookY": -0.5, "phoneLight": true, "rim": "#9fc4ff", "glow": "#ff4a2a",
  "keys": [ { "at": "@и тут", "arms": "shrug", "mood": "surprised", "facing": "front" } ] }
```

- **Положение.**
  - `x` / `y` — точка между ступнями. `[от, до]` двигает персонажа за сцену. Для `walk`/`run` задавайте `x` диапазоном.
  - `scale` — 1 соответствует росту ≈ 390 px. Крупный план: 1.3–1.6 плюс зум камеры.
- **Внешность** — `look`: имя из `looks` вверху доски или объект:
  - `top`: `hoodie` | `tee` | `raincoat` | `none`; `color` — цвет одежды; `pants` — цвет штанов;
  - `hair`: `ponytail` | `bun` | `headband` | `scarf` (платок); `hairColor`;
  - `glasses`: true;
  - `hat`: `cap`, `hatColor`;
  - `skirt`: true.

  Главный герой во всём ролике выглядит одинаково (`looks`). Прохожие разные, у каждого 1–2 цветные детали.
- **Поза.**
  - `legs`: `stand` | `walk` | `sit` | `run`.
  - `arms`: `rest` | `phone` | `mug` | `reach` | `cheer` | `walk` | `hips` | `think` | `pocket` | `ear` (у уха — «звонит») | `write` | `point` | `shrug`.
- **Эмоция** (`mood`): `neutral` | `tired` | `sad` | `happy` | `angry` | `surprised` | `sleep`.
  - Взгляд: `lookX` / `lookY` от −1 до 1.
  - Поворот: `facing` — `front` | `left` | `right`.
- **Свет.**
  - `phoneLight` — голубое свечение экрана на лице.
  - `rim` — контурная подсветка цветом (`rimSide`: `left` | `right`).
  - `glow` — свечение вокруг (злость).
- **Смена позы по ходу сцены** — `keys`. Каждый ключ с `at` меняет `arms`, `legs`, `mood`, `lookX`, `lookY`, `facing`.
- **Сидячий персонаж.**
  - При `legs: "sit"` таз опускается: сиденье должно быть на высоте ≈ `y − 63·scale`.
  - Кладите персонажа на стул так: `chair.y = actor.y`, а `x` стула примерно равен `x` персонажа.
  - На кровати спальни: `y ≈ 980` при `scale` 1.2.
  - В метро сиденье на высоте ≈ 680, значит `y ≈ 772` при `scale` 1.3.
- **Руки.**
  - В позе `write` руки на высоте ≈ `y − 123·scale` (туда ставится `notebook`).
  - В позе `ear` рука у головы.

## 5. Реплики (`texts`)

```json
{ "kind": "say", "text": "Ну и где он?", "actor": "hero", "at": "@где", "dur": 2.5 }
```

- `say` — реплика над головой.
- `think` — мысль (курсив, тёплый цвет).
- `offscreen` — голос за кадром сбоку (`side`: `left` | `right`).
- `notif` — уведомление-плашка у персонажа.
- Без `actor` нужно задать `x` / `y` на экране.

**Реплики короткие:** 2–6 слов. Диктор и реплики не повторяют друг друга.

## 6. Оверлеи (`overlays`): инфографика поверх кадра

| kind | поля | для чего |
|---|---|---|
| `caption` | `text` | подпись-источник внизу слева («Maguire и др., PNAS, 2000», «Первая неделя») |
| `counter` | `from`, `to`, `label`, `suffix`, `time`, `format: "int" \| "mmss"`, `x`, `y` | число бежит от и до |
| `bars` | `items: [{label, value, color}]`, `x`, `y` | 2–3 полоски-сравнения (value в %) |
| `meter` | `label`, `from`, `to`, `color`, `x`, `y` | вертикальная шкала |
| `term` | `title`, `text` | термин с определением |
| `tip` | `title`, `text` | совет |
| `clock` | `time`, `ampm` | часы |

У всех есть `at` и `dur`. **Оверлей не должен закрывать лицо героя**: ставьте его в свободную часть кадра (`x` / `y`) или двигайте героя.

## 7. Локации (`location` + `params`)

**Базовые.**
- `bedroom` — спальня.
  - `tod`: `night` | `dawn` | `morning`;
  - `lamp`: true; `lampOffAt`: секунды;
  - `rain`: true/false (по умолчанию дождь идёт только ночью).
- `kitchen` — кухня.
  - `crosses`: сколько дней зачёркнуто в календаре;
  - `hour`: время на часах, например 7.8.
- `street` — ночная улица под дождём с фонарями.
- `meadow` — светлый луг для финала.

**Из ролика про телефоны.**
- `city` — панорама города.
  - `tod: "dawn"`;
  - `screensOffAt` — волной гаснут голубые экраны в окнах;
  - `blackoutAt` — гаснет весь свет.
- `globe` — Земля из космоса; `lightsOffAt` — гаснут огоньки.
- `cafe` — кофейня с меню и стойкой.
- `crossroad` — перекрёсток с зеброй и светофором; `tod: "evening"`.
- `entrance` — подъезд: почтовые ящики и записка.
- `london` — улица с домами и Биг-Беном.
- `brain` — схема головы с гиппокампом.
  - `growAt` — гиппокамп растёт;
  - `shrink`: true — уменьшается.
- `lab` — белая комната эксперимента.
  - `timerAt`, `timerFrom` (секунды), `timerSpeed` — таймер на стене.
- `grid` — сетка маленьких комнат с людьми (`cols`, `rows`): «тысячи людей».
- `metro` — вагон: окна, реклама, синие сиденья.
- `yard` — вечерний двор у панельки.
- `oldroom` — старая квартира: обои, абажур, комод.
- `telegraph` — телеграф XIX века: свеча, сияние в окне; `sparkAt` — искры.
- `space` — Солнце и выброс.
  - `cmeAt` — момент выброса;
  - `earth` — положение Земли на орбите, 0..1.

**Свои локации студии** лежат в `src/custom/locations.tsx` (см. раздел 9).

## 8. Предметы (`props`)

```json
{ "kind": "notebook", "x": 960, "y": 780, "scale": 0.8, "at": "@записала", "dur": 3, "front": true, "flip": false, "params": { "writeAt": 1 } }
```

- `x` / `y` — точка, где предмет стоит на полу (у висящих в воздухе — центр). Можно задать `[от, до]`.
- `front`: true — предмет рисуется поверх персонажей (стол перед сидящим, тетрадь в руках).

Список предметов:
- `landline` — дисковый телефон; `handset: false` — трубка снята.
- `notebook` — тетрадка; `lines`, `writeAt`.
- `chess` — столик с шахматами и табуретами (сидят на ±150 по x).
- `button` — кнопка с током; `pressAt` — «1.2,3.5», вспышка.
- `bulb` — лампочка-идея.
- `memory` — фото-воспоминание; `icon`: `steps` | `rings` | `dog`, `rot`, `seed`.
- `voicemsg` — голосовое сообщение; `goneAt`.
- `envelope` — письмо; `fly`, `tx`, `ty` — летит в точку.
- `cab` — чёрное такси.
- `buzz` — дрожание вибрации.
- `route` — пунктир маршрута; `fadeAt`.
- `phoneflat` — телефон на столе; `glow`.
- `table` — `w`, `h`, `color`.
- `chair` — `color`.
- `atm` — банкомат.
- `bag` — сумка.
- `bench` — скамейка.

**Свои предметы** — в `src/custom/props.tsx`.

## 9. Новая локация или предмет

1. Откройте `src/custom/locations.tsx` (или `props.tsx`) и посмотрите пример. Для образца годятся и готовые локации в `src/locations.tsx` и `src/locations2.tsx`: окна домов (`Windows`), дождь в окне, градиенты.
2. Локация — компонент `({ t, params }) => <svg viewBox="0 0 1920 1080">…</svg>`. Предмет — `<g>` вокруг точки (0, 0).
3. Стиль:
   - плоский вектор, мягкие градиенты, без обводок;
   - приглушённая палитра, один тёплый источник света;
   - фон не спорит с чёрными силуэтами: персонажи должны читаться.
4. Анимация — только от `t` (секунды сцены). Случайность берите из `rand(i)` (`src/util.ts`): она одинакова в каждом кадре. `Math.random` нельзя.
5. Внутри SVG id градиентов делайте уникальными через `useId()`, как в примере.
6. Зарегистрируйте компонент в `CUSTOM_LOCATIONS` / `CUSTOM_PROPS` и проверьте типы: `npx tsc --noEmit -p .`.
7. Одно место внутри ролика выглядит одинаково, но в каждом новом ролике у него другие время суток, палитра и предметы.

## 10. Команды студии

| Команда | Что делает |
|---|---|
| `npm run transcribe -- <ролик> --lang ru` | расшифровка озвучки из `voice/` → `transcripts/<ролик>.json/.txt` (Whisper на видеокарте; первый раз скачивает модель ≈ 4 ГБ) |
| `npm run timing -- <ролик>` | доска → `data/<ролик>.json` + музыка + таблица сцен |
| `npm run preview -- <ролик>` | листы превью 3×3 → `out/preview/<ролик>-sheet-N.jpg` |
| `npm run preview -- <ролик> 12 15` | отдельные кадры сцен 12 и 15 (`--at 0.2` — момент сцены) |
| `npm run render -- <ролик> --seconds 10 --from 60` | быстрый тест куска |
| `npm run render -- <ролик> --small` | весь ролик → `out/<ролик>.mp4` и лёгкая копия `out/<ролик>-small.mp4` (< 30 МБ, для телефона) |
| `npm run studio` | Remotion Studio в браузере: живой просмотр с таймлайном |
