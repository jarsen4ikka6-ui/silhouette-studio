# Мой плагин анимации — журнал решений

Сюда записываем всё, о чём договорились. Из этого файла потом соберётся SKILL.md — методичка для Claude.

## Решено

**23.10.2026**
- **Формат:** горизонтальный YouTube, 1920×1080.
- **Движок:** Remotion (видео из кода), по образцу плагина stickman-studio.
- **Стиль:** как у канала **Last Soul** — разбор в `style-guide.md`.
- **Жанр (уточнено после разбора):** эмоциональные анимационные короткометражки-притчи на 3–6 минут **без диктора**: силуэты, реплики текстом, цитаты-карточки, музыка и звуки. (Изначально было записано «объясняющие ролики», но референсы — именно такие фильмы.)
- **Вход плагина:** идея или сценарий, а не озвучка. Тайминг строится от текста и музыки.

**23.10.2026 (уточнение)**
- **Два режима в одном визуальном стиле Last Soul:**
  - **Объяснялка** — «что это, почему так работает» (основная ниша);
  - **История** — эмоциональная притча, как у Last Soul.
  Плагин в начале спрашивает режим, и от него зависят сюжетная формула, темп, текст на экране и музыка.
- **Язык ролика выбирается:** русский / английский / другой (человек пишет, какой). Спрашиваем при написании сценария. На этом языке пишутся сценарий, реплики, цитаты-карточки и финальная карточка.
- **Музыка подбирается под нишу и настроение:**
  - объяснялка → позитивная, лёгкая, «любопытная», не отвлекает;
  - грустная история → спокойная, грустная (фортепиано, эмбиент);
  - по ходу сюжета музыка может меняться по главам (грусть → надежда → подъём в финале).
  Общий принцип референса: музыка спокойная, «под ситуацию», никогда не перебивает.
- **Объяснялка — с диктором.** Пользователь даёт озвучку (например, ElevenLabs), плагин расшифровывает её с таймингом слов (Whisper, как в stickman-studio) и строит анимацию под слова. **История — без диктора**, тайминг от текста и музыки.
- **Фоны — кодом.** Библиотека локаций внутри плагина, работает у любого без нейросетей. Новые локации дописываем по образцу существующих.
- **Музыка — генерируем кодом по настроению** (без авторских прав, работает у всех) **+ можно положить свой трек**.
- **Персонажи:** рисуем кодом (SVG): чёрный силуэт, глаза с веками, 1–2 цветные детали одежды; одежда и эмоции — параметры.
- **Плагин — не только исполнитель, но и креативщик.** Сам держит стиль и сам предлагает идеи. Для этого в плагине будут готовые «мозги»:
  - `style-guide.md` — паспорт стиля;
  - `ideas-playbook.md` — банк приёмов: формулы хуков, сюжетная формула, визуальные метафоры, шаблоны сцен;
  - в SKILL.md отдельный шаг: перед раскадровкой предложить 2–3 варианта подачи и свои идеи по сценам.

## Плагином будем делиться

- Плагин раздаётся другим людям (как stickman-studio). Значит, у получателя он должен **работать сам с нуля**:
  - сам проверяет и при необходимости ставит Node.js (Windows: winget, Mac: brew, иначе ссылка на nodejs.org) и говорит, когда перезапустить Claude;
  - сам копирует шаблон движка в папку проекта и делает `npm install`;
  - звуки и музыка генерируются кодом или лежат внутри плагина: без проблем с авторскими правами и без внешних ссылок;
  - никаких личных путей, ключей и файлов автора внутри;
  - понятные сообщения на русском, если что-то сломалось (драйвер видеокарты и т.п.).
- Нужен `marketplace.json`, чтобы плагин ставился одной командой, плюс короткая инструкция по установке для получателя.

## Порядок работы

1. ✅ Ссылки на ролики → разбор стиля → черновик `style-guide.md`.
2. Сценарии конкурентов → разбор структуры и подачи → `ideas-playbook.md`.
3. Рабочий промпт пользователя → встраиваем в методичку SKILL.md.
4. Прототип персонажа и сцены на Remotion → движок → упаковка в плагин.

## Локации всегда разные (23.10.2026)

Главное требование: локации не повторяются из ролика в ролик, а подбираются под сценарий. Как это устроено:
1. **Сначала список мест.** Перед раскадровкой Claude выписывает из сценария все места действия (спальня подростка, больничный коридор, раздевалка спортзала…) и показывает список.
2. **Новые места рисуются под сценарий.** Если такого места в библиотеке нет, Claude рисует новую локацию кодом по правилам стиля (плоский вектор, градиенты, без обводок, приглушённая палитра, тёплые источники света) и добавляет её в библиотеку. Библиотека растёт с каждым роликом.
3. **Даже знакомое место выглядит по-новому.** У каждой локации есть варианты: время суток (утро, день, вечер, ночь), погода, палитра, расстановка мебели, предметы, «зерно» случайности. Кухня из одного ролика не совпадает с кухней из другого.
4. **Внутри одного ролика наоборот:** одно и то же место выглядит одинаково от сцены к сцене. Комната героя остаётся его комнатой, иначе зритель запутается.

## Прототип движка (23.10.2026)

Папка `template/` — будущий шаблон плагина, уже рабочий:
- `src/Character.tsx` — персонаж-силуэт: одежда (худи, футболка, дождевик), причёска (хвост, пучок, повязка), позы рук и ног, эмоции глазами, моргание, контурная подсветка, свечение злости;
- `src/locations.tsx` — локации кодом: спальня ночью (лампа вкл/выкл, дождь в окне), кухня утром (календарь с крестами, часы), улица под дождём с фонарями, луг для светлого финала;
- `src/Texts.tsx` — реплика, мысль, реплика за кадром, уведомление, часы, термин, шкала, совет, цитата, хук-вопрос, финальная карточка;
- `scripts/make-music.mjs` — музыка по настроению (sad / hope / bright), по главам; `scripts/make-sfx.mjs` — звуки;
- раскадровка — JSON (`data/test-story.json`, `data/test-explainer.json`); `npm run preview -- Story` — кадры сцен, `npm run render -- Story` — MP4.

## Озвучка (23.10.2026)

- Озвучку делает сам человек на ElevenLabs. Claude голос не генерирует.
- Файл кладётся в папку **`voice/`** внутри проекта ролика (рядом с `data/`). Подходят mp3, wav и m4a, имя любое. Если файлов несколько, Claude спрашивает, какой взять.
- Можно и просто скинуть файл в чат: Claude сам положит его в `voice/`.
- Дальше плагин сам расшифровывает озвучку через Whisper с таймингом каждого слова (язык из настроек ролика) и строит сцены под слова диктора.
- Порядок для объяснялки: сценарий → человек озвучивает → файл в `voice/` → расшифровка → раскадровка под тайминг → рендер.

## Сценарии

- Разбор двух сценариев конкурентов и формула объяснялки записаны в `ideas-playbook.md`.
- **Утверждены все 7 форматов** (23.10.2026): «Что если», «Как жили раньше», «Древние люди», «Смог бы ты выжить», «Почему так», «Тогда и сейчас», «История» (без диктора). Описаны в `ideas-playbook.md`, раздел 4. Список будет меняться: формат добавляется или удаляется одним блоком.
- **Темы генерируются бесконечно и не повторяются** (`ideas-playbook.md`, раздел 5):
  - темы собираются из осей формата (эпоха × сторона жизни × роль и т.п.), а не берутся из готового списка;
  - 10 тем за раз из разных форматов, без двух похожих в одной подборке, обязательно пара «неожиданных»;
  - журнал `topics-history.md` в рабочей папке пользователя: сделанные темы не повторяются никогда, показанные — не раньше чем через 3 подборки;
  - ротация осей: эпохи и сферы последних 5 роликов на время не берутся.

- **Выбор кнопками** (23.10.2026): человек жмёт формат (7 форматов на двух страницах, по 4 кнопки в окне) и язык, потом получает темы порциями с кнопкой «Ещё темы ↻», пока не выберет. Свою тему можно вписать в поле «Другое». Подробно — `ideas-playbook.md`, раздел 6.
- Окно вопроса Claude Code вмещает максимум 4 кнопки, поэтому темы идут по 3 плюс кнопка «Ещё темы».
- **Сценарий всегда отдаётся файлами** (23.10.2026): полный сценарий `.md` и текст для озвучки `-ozvuchka.txt` в папке `script/`. Оба файла отправляются человеку после написания и после каждой правки.

## Первый полный тест (23.10.2026)

Проверяем всю цепочку на настоящем ролике ~5 минут: выбор формата кнопками → выбор темы → полный сценарий → пользователь озвучивает на ElevenLabs → файл в `voice/` → Whisper → раскадровка под озвучку → рендер.

Ролик «Что если у всех пропадут телефоны?» (5:51, 68 сцен) собран так:
- **Расшифровка:** `@remotion/whisper-webgpu`, модель large-v3-turbo; результат лежит в `data/transcript.json` (тайминг каждого слова) и `transcript.txt`.
- **Доска** `boards/<имя>.json`: время задаётся словами диктора, а не секундами.
  - Начало сцены: `"start": "фраза"`.
  - Внутри сцены можно писать `"@фраза"`, `"@фраза|+0.4"` или `"@фраза|end"`.
  - Смена музыки: `"from": "@фраза"`.
  - Постоянные персонажи описаны в `looks` и подключаются через `"look": "hero"`.
- **Сборка:** `npm run timing -- <имя>` переводит доску в `data/<имя>.json` с секундами и печатает таблицу сцен. При правке озвучки доска не меняется: нужно только перезапустить расшифровку и timing.
- **Голос:** в проекте поле `voice` (+ `voiceAt`, `voiceDb`). Под голосом музыка тише на 8 дБ.
- **Новые локации** (`src/locations2.tsx`): город, глобус, кафе, перекрёсток, подъезд, Лондон, мозг, лаборатория, сетка комнат, метро, двор, старая квартира, телеграф, космос. У спальни появились утро и рассвет.
- **Реквизит** (`src/props.tsx`): стационарный телефон, блокнот, шахматы, кнопка, лампочка, иконки памяти, голосовое, конверт, такси, вибрация, маршрут, банкомат, мебель.
- **Проверка:** перед рендером все кадры собираются в листы 3×3 с номерами и просматриваются целиком.

## Упаковка плагина (23.10.2026)

- **Репозиторий-маркетплейс** `silhouette-studio/`: в нём один плагин `silhouette-video` и один скилл `video`. Вызов: `/silhouette-video:video` или просто «сделай ролик».
- **Студия.** Плагин не работает внутри своей папки: она меняется при обновлениях и недоступна для записи. При первом запуске создаётся **студия** — папка человека (по умолчанию «Документы/Silhouette Studio»). Путь к ней хранится в `~/.silhouette-studio.json`.
- **`tools/studio.mjs`** — установщик на чистом Node, без зависимостей:
  - `create` копирует движок, ставит npm, генерирует звуки и делает пробный рендер на 3 секунды;
  - `update` обновляет движок и не трогает ролики, озвучки и `src/custom`;
  - `where` показывает путь к студии и говорит, нужно ли обновление.
- **Node.js 22.18+:** скрипт расшифровки написан на TypeScript, а такие файлы Node запускает сам только с этой версии. Если Node нет, скилл ставит его через winget или brew и просит один раз перезапустить Claude.
- **Свои локации и предметы** — в `src/custom/`. Обновление их не трогает.
- **`pack.mjs`** собирает плагин из `template/`: копирует движок и справочники, синхронизирует версию и проверяет, что в файлах нет личных путей. Чтобы люди получили обновление, нужно поднять `version` в `template/package.json` и заново запустить `pack.mjs`.
- **Две версии ролика:** полная 1080p для YouTube и лёгкая до 30 МБ (720p) для телефона и мессенджеров. Лёгкая делается флагом `--small`.

## Свой стиль: люди с кожей (0.4.0)

- **Персонажи с живым цветом кожи** вместо чёрных человечков: лицо, уши, руки, ноги, волосы. Цвет кожи (`skin`) выбирается по месту и эпохе. Руки «от первого лица» берут цвет кожи главного героя (`looks.hero`) через `useHeroSkin()`.
- **Руки у длинной одежды** (накидка, платье, пальто) висят по бокам, в профиль видна одна рука. На накидке нет белых вставок — только пояс и кайма в тон.
- **Головные уборы:** повязка лежит поверх волос, платок закрывает голову целиком и спадает сзади. Цвет ткани — `hatColor`, `hairColor` — только волосы.
- **Число всегда докручивается:** `npm run timing` продлевает слишком короткий показ `stat`/`counter`/`meter`/`bars`, а в кадре число не бежит дольше, чем видна табличка. Если сцены не хватает — предупреждение «ВНИМАНИЕ».
- **Кадр-деталь резкий:** у `insert` и `pov` центр кадра не размывается, размытие только по краям.

## Мультик «Что, если бы ты…» (0.5.0)

- **Второй стиль — toon** (`"style": "toon"` в доске): белые круглые головы с обводкой, яркая одежда, ночные локации `t-*`, плашки сверху («ДЕНЬ 1», «ПОТРАЧЕНО»), жёлтые плашки и крупные слова. Персонажи и брендинг свои, картинки конкурента не копируются.
- **Озвучка одним голосом.** Кто говорит, плагин узнаёт по разметке `ИМЯ:` в сценарии: `npm run lines` сопоставляет сценарий с расшифровкой, `npm run timing` ставит пузыри над говорящим и открывает ему рот под громкость голоса.
- **Сценарий по мастер-промпту** `script-prompt.md`: 10–15 минут ≈ 1500–2200 слов ≈ 15–22 тысячи знаков. Два файла: `.md` с именами и `-ozvuchka.txt` без имён.
- **Свой персонаж:** перед темами вопрос «Да / Нет». Картинки на белом фоне → `characters/<имя>/`, внешность подбирается полями `Look` и сохраняется в `characters/<имя>.json`; в доске `"char:<имя>"`. Персонаж перерисовывается кодом в стиле мультика, это не сама картинка.
- **Пузырь не закрывает людей:** над головой; на крупном плане — сбоку, где нет соседа; если тесно — над головой у верха кадра.
